# diagram→mermaid 还原（opt-in 子流程）

## 这是什么 / 何时用

auto 转换（Phase 0，`pipeline.py --mode auto`）完成、产物含正文 md + in-body 图片后，
**用户手动触发**的一个可选子流程：把「明显是流程图 / 思维导图」类的**栅格图**还原成 mermaid
代码块。

**不属于 Phase 0 auto 管线，不改任何脚本，不影响可复现契约。** 只有用户显式要求（如「还原
mermaid 图」）才跑。

### 四条硬约束（地基，不可违背）

1. **图无结构可解析** —— 产物里的图是栅格（webp/png/jpg/gif），mermaid 源已在渲染 / 栅格化
   时丢失。还原 = 视觉模型看图重画，**天生非确定**（同图两次结果可能不同）。
2. **不污染可复现契约** —— 绝不塞进 auto 管线、绝不加 CLI flag、绝不改脚本。auto 保持「同
   输入同输出、可验证」。
3. **只还原 mermaid 能表达的** —— flowchart / mindmap / 时序图 / 类图 / 状态图等。**定量图
   （带坐标轴的曲线 / 散点 / 柱状 / 直方 / 分布）一律不碰**，mermaid 语法表达不了坐标系 + 连续
   数据。
4. **人来定验收** —— skill 判不了「够不够像」。渲染出来跟原图并排，留用 / 丢弃由用户决定。

---

## 启发式初筛判据

对产物里每张 in-body 图，按下面分档。判据用于视觉判断（看图执行），非脚本。

### 排除（定量图 —— 命中任一即排除，不还原）

- 有**坐标轴 + 刻度数字**（横纵轴上 `0 5 10 15…` 或 `0.0 0.5 1.0…`）
- **连续曲线** / **散点云** / **柱状条** / **直方图**
- 图例框标注数据系列（如「N(0,1)」「t 分布」「简单收益率 %」「有效前沿」）

### 纳入候选（命中即纳入）

- **色块矩形**（圆角或直角），文字全在块内
- 块与块之间有**有向箭头**连线
- **放射状**布局（中心一个词，向外多条彩色分支）→ 疑似 **mindmap**
- **层级树**（自上而下或自左而右分叉 / 汇聚）→ 疑似 **flowchart**
- **无任何坐标轴**

### 拿不准

纳入候选并标 `low-confidence`（例：带边框的图例、图表 + 文字块混合图）。交用户裁定。

## 五步子流程

### 1. 圈定候选（启发式初筛）

按上面判据对每张 in-body 图分档，输出一张**候选清单**：

```
图路径 | 档位(候选/low-confidence/排除) | 疑似子类型(flowchart/mindmap/…)
```

此步**不动图、不写 md**。

### 2. 用户确认清单

清单给用户，用户划掉误判、补漏判。
**无人值守时**：自动纳入所有「候选」与「low-confidence」，在后续产物里标注 `待审`，等用户回来审。

### 3. 视觉重画（子 agent 逐张）

每张确认图派一个**视觉子 agent**（prompt 模板见下）。子 agent 看图 → 写 mermaid → 返回：
- mermaid 源码
- 不确定点清单（哪条连线方向 / 哪层归属拿不准）

一个子 agent 只处理一张图。

### 4. 渲染对比（强制兜底）

子 agent 把写好的 mermaid 渲染成图（命令见「渲染」节），跟原图**并排**给用户：
- **渲染失败**（语法错）→ 子 agent 自修一轮；仍失败 → 标「需人工」，保留原图，不替换。
- **渲染成功** → 原图 vs 渲染图两张都摆出来供比对。

### 5. 用户验收 + 落盘

用户看每对图判「够像 / 不像」，按替换表落盘。

---

## 落盘替换表

| 验收 | md 内容 | files/ 里的图 |
|---|---|---|
| 够像 | 把 `![](图)` 替换成 ` ```mermaid ` 代码块 | **删除**（含从 ZIP / files 移除） |
| 不像 | `![](原图)` 不变 | 保留 |
| 渲染失败 / 需人工 | `![](原图)` + `<!-- diagram-to-mermaid: 需人工 -->` | 保留 |
| 无人值守（默认保守） | mermaid 代码块 + 原图**并存** + `<!-- diagram-to-mermaid: 待审 -->` | **保留**（绝不无人删图） |

原图格式不假定为 webp —— 判据与替换对任意栅格格式（webp/png/jpg/gif）一致生效。

## 视觉子 agent prompt 模板

```
你是视觉识别子 agent。输入一张图片路径，任务是把它还原成 mermaid 源码。

输入：<图片绝对路径>

要求：
1. 判定图类型：flowchart（框+箭头，层级/流程）还是 mindmap（中心词+放射分支），
   或其它 mermaid 类型（时序图/状态图/类图）。写对应 mermaid。
2. 文字逐字照抄图里的内容，含符号（α β ρ σ ω R² Rf Rm 等）、换行、中英文混排。
   图内换行在 flowchart 节点里用 <br/>。
3. 遵守 GitHub mermaid 渲染规则：
   - 边标签含特殊字符（() [] {} . ' 等）→ 用管道+双引号包：-->|"标签"|
     不要用内嵌简写 -- 标签 -->（() [] {} 会被当节点形状关键字报错）。
   - 节点/边标签内避免 `1.` `2.` 这类模式（GitHub 会误当有序列表，显示
     "Unsupported markdown: list"）；改用 ① ② 或去掉点号。
4. 渲染自检：用 Playwright 加载 mermaid.js 渲染，或 npx @mermaid-js/mermaid-cli
   渲染成 PNG。渲染失败（语法错）自己修一轮。
5. 标注不确定处：哪条连线方向拿不准、哪个节点归属拿不准，明确列出。

返回：
- mermaid 源码（在 ```mermaid 代码块里）
- 渲染出的图片路径
- 不确定点清单（没有则写「无」）
```

## 渲染

**首选 Playwright**（skill 已依赖 Playwright MCP，CJK 字体正常渲染；cairosvg 被 skill 拒
是因为把中文渲成豆腐块）：无头浏览器加载一个引入 mermaid.js 的 HTML，注入 mermaid 源，
渲染后截图。

**备选 mmdc**（`@mermaid-js/mermaid-cli`）：

```bash
# 本机有 node + npx，无全局 mmdc，首次 npx 会拉包（慢一次）
echo '<mermaid 源>' > /tmp/diagram.mmd
# 无 GUI 的 ssh 环境：puppeteer 需 --no-sandbox，否则渲染失败
printf '{"args":["--no-sandbox"]}' > /tmp/pptr.json
npx @mermaid-js/mermaid-cli -i /tmp/diagram.mmd -o /tmp/diagram.png -p /tmp/pptr.json
```

CJK 中文在 mmdc 下实测正常显示，flowchart 与 mindmap 均能渲染。mindmap 含空格/斜杠的
节点文字用 `["..."]` 包裹保 GitHub 解析安全。若某图缺字或语法不被 mmdc 版本支持，退回
Playwright 或直接交 GitHub 渲染验证。
